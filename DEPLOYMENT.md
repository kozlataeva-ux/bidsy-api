# Реквизиты оператора

Реквизиты хранятся в переменных окружения сервера, вне GitHub:

- `BIDSY_OPERATOR_NAME` — ФИО.
- `BIDSY_OPERATOR_EMAIL` — email для обращений.
- `BIDSY_OPERATOR_ADDRESS` — адрес для обращений.

Задайте все три значения в настройках окружения хостинга до развёртывания
этой версии. Перезапустите приложение и проверьте `/privacy`.
Локальный `.env` автоматически не загружается; переменные должны быть
переданы процессу Flask или Gunicorn.

Если хотя бы одно значение отсутствует, `/privacy` вернёт HTTP 503.
Не развёртывайте эту версию до настройки окружения.

Переменные окружения не являются шифрованием. За их хранение и доступ
к ним отвечает инфраструктура хостинга. Значения не передаются в исходники
и подставляются сервером в HTML при открытии политики. На публичном сайте
они доступны всем посетителям. Ответ `/privacy` имеет `Cache-Control: no-store`.

Удаление реквизитов из файлов не удаляет их из старых Git commits.
Очистка уже опубликованной истории требует отдельного согласования.
